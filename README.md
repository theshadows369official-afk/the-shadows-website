# The Shadows — Cinematic Website Starter

A responsive, navy-blue cinematic starter site for The Shadows.

## Preview locally
1. Extract this ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Internet is needed for the optional Google Fonts; the site still works without them.

## Publish free with Cloudflare Pages
1. Create a GitHub account and a repository named `the-shadows-website`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. In Cloudflare Dashboard choose Workers & Pages → Create → Pages → Connect to Git.
4. Select your repository and deploy.
5. For a plain HTML site, leave the build command blank and set the output directory to `/` (repository root).

## Before public launch
- Replace `hello@theshadows.example` in `index.html` with your real contact email.
- Replace the gallery placeholders with your own Minecraft screenshots.
- Add real pack version, compatibility, installation, credits and download details only after testing.
- Do not upload a pack unless you have permission to redistribute every included asset.
- This is an unofficial Minecraft fan project. Keep the non-affiliation notice.
- No analytics, ads, payments or tracking are included by default.
